# 월 지출 계산기

> 🔗 **배포 주소**: [https://gwangco.github.io](https://gwangco.github.io)

고정 지출과 일별 지출을 입력하면 한 달 총지출을 계산해 주는 웹 계산기입니다.
별도 프레임워크 없이 **HTML · CSS · Vanilla JavaScript**만으로 만들고 **GitHub Pages**로 배포했습니다.

## 주요 기능
- 고정 지출 / 일별 지출 항목 추가·삭제 및 목록 렌더링
- 금액 천 단위 콤마 포맷팅과 원화 표기
- 월 총지출 자동 계산
- 구글 검색 노출을 위한 메타 태그(SEO) 설정
